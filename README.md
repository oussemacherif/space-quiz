# Orbit — Space Quiz

Orbit is a lightweight, single-page space trivia quiz. Answer questions with the mouse or the 1–4 number keys, use Enter to check and advance, and replay the quiz after seeing your score.

## Run locally

No build tools, dependencies, or server are required. Open `index.html` in a web browser.

## Deployment

The GitHub Actions workflow in `.github/workflows/deploy-pages.yml` publishes `index.html` to GitHub Pages whenever changes are pushed to `main`, and can also be run manually from the Actions tab.
